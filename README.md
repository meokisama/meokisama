I'm **Hoàng Đình Sáng**, known online as **Meoki**. I build quiet, useful software for the things I love: Japanese, light novels, and interfaces that feel alive.

I started as a freelance graphic designer in 2016, studied information security at university, and came out a full-stack engineer who cares about how things look as much as how they hold up. By day I ship web software. After hours I learn Japanese, read from a *tsundoku* pile that never gets shorter, and open-source the tools I wanted for my own reading.
